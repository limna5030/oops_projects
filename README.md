# Inventory Management System (Python OOP)

A Python-based inventory management project demonstrating Object-Oriented Programming (OOP) principles such as classes, objects, encapsulation, and file handling.

## Project Structure

- `working2.py` — Main application script containing the core inventory logic and operations.
- `oops2.py` — Object-oriented module defining the inventory classes and methods.
- `inventory_report.txt` — Generated text report logging current stock details and inventory summaries.

## Features

- Add, update, and track inventory items using Python classes
- Manage stock quantities and item details
- Export formatted inventory summaries to `inventory_report.txt`
