# Bank Management System (Python OOP)

A Python-based bank management application demonstrating Object-Oriented Programming (OOP) principles such as classes, objects, encapsulation, and file handling for transaction logging.

## Project Structure

- `working.py` — Main application script handling user interaction, account operations, and menu flow.
- `oops.py` — Object-oriented module defining bank account classes, balance management, and transaction methods.
- `transactions.txt` — Text log storing deposit, withdrawal, and account transaction history.

## Features

- Create and manage bank accounts using Python classes
- Perform deposits, withdrawals, and balance inquiries
- Record and track transaction history in `transactions.txt`
